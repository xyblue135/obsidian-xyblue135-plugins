# xyblue135 · 代码块增强

> **开源插件**：xyblue135 维护的开放源代码插件，仓库公开、可自由查看与复用。
> **兼容原则**：插件 ID 保持 `00_xyblue135-code-block-wrap`，升级包不携带 `data.json`，覆盖安装时保留用户本地配置与历史状态。

维护者：**xyblue135**

---

一个极简 Obsidian 代码块插件，只处理围栏代码块的显示与换行，不影响普通正文，也不影响行内代码，不修改 Markdown 文件本身。

## 功能

- 默认关闭代码块自动换行，长代码保持真实单行。
- 阅读模式 / 已渲染 Live Preview 中，超长代码只在代码区域内部横向滚动。
- 代码块顶部提供独立工具栏，原生复制按钮移到右上角，不再遮挡第一行代码。
- 默认启用「紧凑深色」外观：顶部工具栏 20px、复制按钮 16×16px。
- 编辑态代码块只在最底部显示唯一一个横向滚动条，滚动范围由最长一行决定。
- 左侧 Ribbon 与命令面板均可切换自动换行；状态会保存，重载不丢失。

## 设置项

在 Obsidian → 设置 → xyblue135 · 代码块增强 中可实时调整：

- 自动换行开关
- 紧凑深色 / 跟随 Obsidian 主题
- 是否显示左侧 `>_` 标记
- 工具栏高度、复制按钮与图标大小
- 代码区上下/左右内边距、圆角、横向滚动条高度
- 代码块背景、工具栏、边框、文字、弱化文字、悬停背景、强调色等颜色
- 自定义代码块背景独立开关
- 显示顶部复制栏开关（默认关闭）
- 语法高亮开关（默认关闭，关闭后代码为单色文本）

所有设置自动保存、实时生效，并提供一键恢复推荐默认值。

## 安装

把整个文件夹复制到：

```text
<你的仓库>/.obsidian/plugins/00_xyblue135-code-block-wrap/
```

至少包含：

```text
manifest.json
main.js
styles.css
```

然后重启或重载 Obsidian，在 设置 → 第三方插件 中开启 **xyblue135 · 代码块增强**。

## 源码说明

- `main.ts`：TypeScript 源码，中文注释。
- `main.js`：Obsidian 直接运行的 JavaScript 入口，中文注释。
- `styles.css`：代码块换行、顶部工具栏、复制按钮和横向滚动布局，中文注释。
- `manifest.json`：插件元信息。
