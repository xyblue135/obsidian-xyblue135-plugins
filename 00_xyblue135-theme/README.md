# xyblue135 · 主题

无需编写 CSS 片段即可自定义 Obsidian 外观的主题定制插件。通过直接覆盖 Obsidian 的标准 CSS 变量，实时调整颜色、字号、间距等。

## 功能

- 明暗双配置：浅色 / 深色两套外观可分别独立设置
- 背景：主背景、次背景、主/次背景备用色
- 链接与强调：内部链接、外部链接、未解析链接、粗体、斜体、高亮背景
- 排版：正文字号、行高、段落间距，以及正文 / 次要 / 淡色文字颜色
- 标题：H1–H6 各级单独设置颜色、字号、字重、行高
- 高级：列表缩进与间距、分割线、引用块、行内代码与代码块、标签

## 附加能力

- 一键导出当前设置为 JSON，便于分享或备份后重新导入
- 一键导出当前样式为独立 CSS 片段，停用插件也能继续生效
- 支持从 Base16 YAML 配色方案一键填充配色

## 安装

手动安装：将本目录 `00_xyblue135-theme` 复制到 vault 的 `.obsidian/plugins/` 下，然后在「设置 → 第三方插件」中启用。

## 说明

- 主要面向 Obsidian 默认主题设计；若使用社区主题或自定义 CSS 片段，且它们修改了相同的 CSS 变量，可能出现不生效或相互覆盖。
- 本插件基于 [theme-basics](https://github.com/narwhai/theme-basics)（MIT License）汉化而来。
